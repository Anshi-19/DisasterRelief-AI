Performance and resources

Methodology

  • Same 28 questions for every model.
  • Same retrieval setup, knowledge bases, repository index, top-k, temperature, and max output tokens.
  • Embedding model: nomic-embed-text:latest.
  • Repository questions: Chroma collection disaster_relief_code.
  • RAG questions: Week 3 collection disaster_relief via retrieve_documents().
  • Correctness 1.0 / 0.5 / 0.0; relevance 1.0 / 0.5 / 0.0; hallucination 0 / 0.5 / 1.0.
  • Hit@K / MRR / P@K / R@K from dataset relevant_files.
  • Latency from wall-clock generate calls; tokens and durations from Ollama.
  • CPU/RSS sampled from local Ollama processes with psutil.
  • Code-generation snippets executed against backend/.
  • Failed Ollama calls are recorded, retried twice, and excluded from quality averages.
